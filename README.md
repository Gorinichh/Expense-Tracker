## Описание программы
Expense Tracker — это простое GUI-приложение на Python (Tkinter) для отслеживания личных расходов. 
Оно позволяет пользователям добавлять расходы, категоризировать их, фильтровать по датам и категориям, 
а также видеть общую сумму затрат за выбранный период. Данные сохраняются локально в формате JSON.

## Требования
- Python 3.x
- Стандартные библиотеки: `tkinter`, `json`, `os`, `datetime` (установлены по умолчанию с Python)
